# Функция React.lazy

React.lazy — это функция в React, которая позволяет реализовать "ленивую загрузку" (_lazy loading_) компонентов — то есть загружать их не при старте приложения, а только в тот момент, когда они действительно нужны для рендера.

При сборке React‑приложения код обычно объединяют в один или несколько бандлов (bundles). Если импортировать все компоненты статически, начальный бандл получится большим — страница будет дольше загружаться. React.lazy помогает разбить код на чанки и подгружать отдельные части по мере необходимости, тем самым ускоряя первую отрисовку.

React.lazy принимает функцию, которая делает динамический импорт через import() и возвращает Promise, разрешающий в модуль с компонентом (обычно — в default-экспорт).

Пример:

```jsx
import { lazy, Suspense } from 'react';

const HeavyComponent = lazy(() => import('./HeavyComponent'));

function App() {
  return (
    <Suspense fallback={<div>Загрузка...</div>}>
      <HeavyComponent />
    </Suspense>
  );
}
```

Важные моменты:

- **Динамический импорт**: `import('./HeavyComponent')` асинхронно загружает отдельный чанк кода
- **Suspense обязателен**: любой компонент, созданный через React.lazy, должен рендериться внутри `<Suspense>`. Пропс fallback задаёт UI, который показывается, пока компонент загружается (например, спиннер, скелетон и т. п.)
- Объявление на уровне модуля: lazy-компонент создают вне тела других компонентов (на верхнем уровне файла), чтобы не пересоздавать его при каждом рендере

Типичные сценарии использования:

1. Ленивая загрузка страниц в роутинге: каждая страница (маршрут) — отдельный chunk:

```jsx
const Home = lazy(() => import('./pages/Home'));
const About = lazy(() => import('./pages/About'));
```

2. Тяжёлые компоненты: графики, редакторы кода, большие таблицы — загружаются только при необходимости.
3. Компоненты ниже «сгиба» экрана: если часть контента не видна сразу, её можно подгрузить позже.

Для обработки ошибок загрузки (если чанк не загрузился) дополнительно используют **ErrorBoundary**.
